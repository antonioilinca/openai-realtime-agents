# Contributing to AION

## Development setup
1. Ensure Python 3.12+ is installed.
2. Install dependencies: `pip install -r requirements.txt`.
3. Copy `.env.example` to `.env` and update values as needed.
4. Run tests with `pytest`.

## Code style
- Follow PEP 8 and keep functions small.
- Add or update tests for new features.
- Use structured logging (JSON logs) for background jobs.

## Commit guidance
- Keep commits focused and descriptive.
- Ensure documentation is updated when behavior changes.
