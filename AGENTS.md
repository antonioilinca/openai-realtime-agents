# AION Repository Guidance

## Scope
These instructions apply to the entire repository.

## Expectations
- Keep modules small and cohesive.
- Prefer explicit, readable code over heavy abstractions.
- Include structured logging for background tasks.
- Every ingestion or summary output must include citations with URL, publication date, ingestion date, and a content hash.
- Maintain clear separation between facts, interpretations, and hypotheses in any summary artifacts.
- Provide deterministic, testable behavior where possible.

## Formatting
- Use Python type hints in new Python code.
- Keep functions short and single-purpose.
